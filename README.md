## Overview

LineTwin is a spatiotemporal digital twin designed to predict and prevent
assembly line bottlenecks in mixed modern/legacy manufacturing environments.
It uses soft-sensor inference to fill "dark data" gaps and a graph-based ML
engine to issue prescriptive alerts.
